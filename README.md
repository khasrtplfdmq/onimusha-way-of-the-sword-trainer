## 📖 About

Onimusha: Way of the Sword by Capcom is the long-awaited return of the iconic samurai series. Set in the Sengoku period, you wield demonic powers alongside traditional swordsmanship to fight supernatural enemies. The game revives the 2000s-era action pacing with modern production values.

| Problem | Status |
|---------|--------|
| Oni soul absorption requires perfect timing on weakened enemies before dying | ✅ Solved |
| Fluorite orb farming for upgrades requires replaying completed chapters | ✅ Solved |
| Enemy poison and paralysis stacks overwhelm health recovery between rooms | ✅ Solved |
| Darkness mode demon form has finite duration requiring resource management | ✅ Solved |

The **Onimusha: Way of the Sword Trainer** solves all these issues, giving you complete control so you can focus on enjoying the game.
